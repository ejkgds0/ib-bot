# Анализ кода (Bandit)

Датасет содержит результаты статического анализа безопасности
исходного кода telegram-бота bot.py с использованием сканера Bandit.

**Структура**

- data/scan_findings.csv - таблица найденных проблем
- raw/bandit_report.txt - исходный вывод сканера
- meta/scan_findings.meta - метаданные сканирования
- report/expert_assessment.md - экспертная оценка находок
- report/sources.md - источники и инструменты
