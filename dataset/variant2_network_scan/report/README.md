# Анализ сетевой инфраструктуры

Датасет содержит результаты сканирования легальной тестовой цели
scanme.nmap.org с использованием Nmap, Masscan и Nikto, а также
демонстрацию получения официальных IP-диапазонов GitHub через
публичный Meta API.

**Структура**

- data/scan_findings.csv - таблица находок (8 записей)
- raw/nmap_result.txt -  исходный вывод Nmap
- raw/masscan_output.txt - исходный вывод Masscan
- raw/nikto_report.html - отчёт Nikto
- meta/scan_findings.meta -  метаданные сканирования
- report/expert_assessment.md - экспертная оценка
- report/sources.md - источники
